# Локализация (RU / EN)

Система перевода игры. Языков ровно два: `LangCode.RU` и `LangCode.EN`.
Язык переключается в любой момент (меню или пауза в игре) — весь текст и
переводимые текстуры меняются мгновенно. Выбор языка хранится в
`PlayerPrefs["Language"]`.

## Главный принцип: русский исходник — это ключ

Нигде в коде/префабах НЕ нужны строковые "ключи". Пишите русскую реплику как
обычно, а при показе она автоматически прогоняется через `Language.Get(ru)`:
если выбран EN и для строки есть перевод — покажется он, иначе покажется русский.

```csharp
TalkUI.instance.Say("Заткнись");        // покажет "Заткнись" или "Shut up"
tasksUI.ShowTask("Выключите радио");     // покажет задачу на нужном языке
```

## Как добавить НОВУЮ реплику / задачу / реакцию с переводом

1. Напишите русскую строку как обычно — в коде (`Say`, `ShowTask`, `ShowHint`,
   `WinPanel.SetText`) или в префабе через `React` / `ChangeQuest` (UnityEvent).
2. Откройте [`LocalizationData.cs`](../LocalizationData.cs) и добавьте одну пару:
   ```csharp
   ("Точно та же русская строка", "English translation"),
   ```
   Ключ должен ПОБУКВЕННО совпадать со строкой из п.1 — включая теги
   `<b>...</b>`, переносы `\n`, пробелы и скобки.

Если перевода нет — в EN-режиме просто останется русский, ничего не сломается.

## Статичные подписи в сценах (кнопки меню, заголовки)

На TMP-объект вешается компонент **`LocalizedText`**. Русский ключ он берёт из
самого текста подписи при загрузке (или из поля `sourceOverride`). При смене
языка перерисовывается сам. Уже навешан на все статичные подписи в
`MainMenu`, `LoadingScene`, `GameScene`.

> НЕ вешайте `LocalizedText` на тексты, которыми управляет код
> (`TalkUI` / `TasksUI` / `HintUI` / `WinPanel`) — они локализуются сами.

## Переводимые текстуры

Текстуры с текстом лежат парами в `Assets/Models/TranslatableModels/`
(`*_ru` и `*_en`). На объект вешается:

- **`LocalizedTexture`** — для 3D-меша: подменяет текстуру на материале через
  `MaterialPropertyBlock` (общий материал не портится). Свойство шейдера —
  `_BaseMap` (URP Lit). Уже навешан на `note`, `newspaper`, `table_book`
  в `NormalRooms` и `LabirintRooms`.
- **`LocalizedSprite`** — для UI `Image` или `SpriteRenderer` (две `Sprite`).

Чтобы добавить новую переводимую текстуру: положите `foo_ru`/`foo_en` в папку,
повесьте `LocalizedTexture` на объект и назначьте обе текстуры.

## Кнопки переключения языка

Кнопки RU/EN в сценах уже вызывают `Language.ChangeLanguage("RU"/"EN")` через
свой `onValueChanged`. Компонент **`LanguageToggle`** (навешан на `RUToggle` /
`ENToggle`) лишь подсвечивает активный язык при загрузке и при смене — без
повторного вызова колбэка.

## Шрифт и латиница (важно)

Игровой шрифт **`Old-Soviet`** статичный и НЕ содержит апострофа `'`, кавычек
`"` и пары других латинских знаков. Чтобы английский текст рендерился целиком,
к `Old-Soviet` добавлен **fallback-шрифт `LiberationSans SDF`** (в списке
fallback самого ассета шрифта). Благодаря этому можно свободно писать английские
сокращения (`I'll`, `won't`) — недостающие глифы берутся из fallback.
Если поменяете основной шрифт — проверьте покрытие латиницы или сохраните
fallback.

## Файлы

| Файл | Назначение |
|------|-----------|
| `Language.cs` | Движок: `Get`, `ChangeLanguage`, событие `OnLanguageChanged`, хранение в PlayerPrefs |

| `Localization/LocalizedTexture.cs` | Текстуры на 3D-мешах |
| `Localization/LocalizedSprite.cs` | Спрайты в UI / на 2D-объектах |
| `Localization/LanguageToggle.cs` | Синхронизация подсветки кнопок RU/EN |
